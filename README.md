# Samsung-Innovation-Campus

This repository contains materials and notebooks from the Samsung Innovation Campus program.

## Adding Files from Google Colab

You can easily add your Colab notebooks to this repository:

1. **Open your notebook in Google Colab**
2. **Connect to GitHub:**
   - Go to `File` → `Save a copy in GitHub`
   - Select this repository: `Nishant-172-bot/Samsung-Innovation-Campus`
   - Choose the `main` branch
   - Add a descriptive commit message
   - Click `OK`

3. **Or use the notebook's built-in link:**
   - Your notebooks will automatically include a "Open in Colab" badge
   - Click this badge to open and edit notebooks directly in Colab
